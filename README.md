# Project: IQR Boxplot (Outlier Treatment)
-> This project demonstrates how to detect and handle outliers using the Interquartile Range (IQR) method and visualize them using Boxplots.
-> It also explores two effective outlier handling strategies — Trimming (removing outliers) and Capping (limiting extreme values).

## Highlights:-

-> Detect outliers using IQR (Q1, Q3, and IQR range)
-> Visualize outliers using Boxplots
-> Apply Trimming to remove extreme points
-> Apply Capping to replace outliers with boundary values
-> Compare data distributions before and after treatment

## Libraries Used:-

-> pandas
-> numpy
-> matplotlib
-> seaborn

## Goal:-

-> To understand how the IQR method works for outlier detection and explore how trimming and capping affect the overall data distribution and model performance.
